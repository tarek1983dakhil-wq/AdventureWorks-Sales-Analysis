
# AdventureWorks Sales Analysis | SQL Server

## Project Overview

This project analyzes sales data from the Microsoft AdventureWorks2022 sample database using SQL Server and SQL Server Management Studio (SSMS).

The goal is to explore sales performance, identify top-selling products, and analyze revenue trends over time.

## Tools Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## Analysis Performed

1. Sales order data exploration
2. Total orders, total revenue, and average order value
3. Yearly sales analysis
4. Monthly sales analysis
5. Top 10 products by sales value

## Key Findings

- The dataset contains 31,465 sales orders.
- Total order value is approximately 123.2 million.
- Average order value is approximately 3,916.
- The highest annual sales total occurred in 2013.
- Mountain-200 Black, 38 was the top product by sales value in the analysis.

Note: Total order value includes tax and freight. The dataset is historical sample data.

## SQL Techniques

- SELECT and TOP
- COUNT, SUM, and AVG
- GROUP BY and ORDER BY
- YEAR and MONTH
- INNER JOIN
- ROUND
